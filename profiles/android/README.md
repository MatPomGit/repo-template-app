# Android (opcjonalne)

Dla Kotlin/Java: projekt Gradle, kontrola minSdk/targetSdk, `gradle.lockfile` lub wersje przypięte, instrumented tests, zgoda na sensor/camera/BLE, test przerwań i eksportu.
Wydania: podpisany APK/AAB w Releases; współdzielony SDK, jeśli powstanie, może być osobnym `lib-*` publikowanym w Maven/GitHub Packages.
Nie zakładaj dostępu do hardware ani że test emulatora potwierdza zachowanie fizycznego sensora.
