# Agent: profil Desktop

Stosuj nadrzędny [AGENTS.md](../../AGENTS.md), [procedurę](../../.github/AGENT_WORKFLOW.md) oraz lokalny [README](README.md). Wymagania dotyczą jedynie platform, które aplikacja rzeczywiście deklaruje.

Zapisz Windows/Linux, architekturę CPU, runtime, zależności natywne i sposób instalacji. Uruchomienie na jednym OS nie potwierdza kompatybilności z innym. Dla dostępu do USB/BLE/kamery wymagaj jawnej zgody, izolacji i testu docelowego urządzenia. Kontroluj trwałość danych, restart oraz możliwość odtworzenia stanu. Instalator i proces wydania wymagają osobnego podpisu, raportu i upoważnienia; sam test jednostkowy nie wystarcza.
