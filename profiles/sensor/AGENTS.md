# Agent: profil aparatury

Stosuj nadrzędny [AGENTS.md](../../AGENTS.md), [procedurę](../../.github/AGENT_WORKFLOW.md) oraz lokalny [README](README.md).

Nie łącz się z aparaturą ani nie zmieniaj firmware, kalibracji i sterowania bez upoważnienia i aktualnej instrukcji bezpieczeństwa. Zidentyfikuj urządzenie, SDK, wersję firmware, jednostki, częstotliwości próbkowania, synchronizację i format eksportu. Zapewnij rozróżnienie danych `synthetic`, `not_verified` i rzeczywistych pomiarów; brak urządzenia oznacza `NOT_RUN`. Nie umieszczaj danych uczestników ani prywatnych identyfikatorów w publicznym repo; identyfikatory potrzebne operacyjnie przechowuj w zatwierdzonym katalogu prywatnym.
