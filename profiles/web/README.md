# Web / PsychoJS / jsPsych (opcjonalne)

Oddziel frontend, prywatny backend i politykę danych. GitHub Pages to host statyczny, nie miejsce przechowywania ankiet i pomiarów.
Dla eksperymentów czasu reakcji odnotuj przeglądarkę, monitor, liczbę klatek, fokus, zmienność opóźnień i testy timing.
Dodaj politykę uprawnień, consent flow i wersjonowanie bodźców oraz kwestionariuszy (z uwzględnieniem licencji).
