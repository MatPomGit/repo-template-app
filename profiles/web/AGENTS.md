# Agent: profil Web

Stosuj nadrzędny [AGENTS.md](../../AGENTS.md), [procedurę](../../.github/AGENT_WORKFLOW.md) oraz lokalny [README](README.md).

Rozdziel frontend od prywatnego backendu i magazynowania danych. GitHub Pages może publikować zasoby statyczne, ale nie jest bazą danych uczestników. Przed integracją sprawdź zgody, cookies, uprawnienia przeglądarki, kontrolę sieci i licencje bodźców. W eksperymentach czasu reakcji odnotuj wersję przeglądarki, parametry ekranu, fokus i opóźnienia. Test JS w środowisku CI nie jest walidacją dokładności czasowej na docelowym stanowisku. Publikacja Pages pozostaje oddzielną czynnością.
